# Intro media

`intro.gif` previews camera zoom, pan and scrolling from an actual headless MCP recording. It is optimized for inline playback in the README.

`intro.mp4` is the typing demo with original title/end cards and synthesized keyboard sound. No stock music, external keyboard samples or stock images are used.

The capture uses a separate test profile without user files. It demonstrates typing, selection and cursor movement while preserving normal editor UI. It does not demonstrate a manual recording-button click. Captions are explanatory post-production overlays.
